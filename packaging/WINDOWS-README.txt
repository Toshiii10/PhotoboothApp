PHOTOBOOTH STUDIO - WINDOWS x64

Installer: run the setup EXE, install, then double-click the Photobooth Studio
desktop or Start menu icon. Java and all application libraries are included.

Portable ZIP: extract the ENTIRE ZIP to a permanent folder first, then open
Photobooth Studio.exe. Optionally run Create Desktop Shortcut.cmd once.
Keep the runtime and app folders beside the EXE. Moving the folder breaks
an existing portable shortcut; run the shortcut creator again after moving it.

No Java, Maven, IDE, terminal commands, or internet connection is needed to run.
The installer is unsigned; Windows may show a publisher/reputation prompt.

Select your physical webcam in Camera Device. If it cannot open, close other
camera apps and check Windows Settings > Privacy & security > Camera.
Only one Photobooth Studio window may use your local photo library at a time.

Photos, frames and database: %USERPROFILE%\Photobooth
Troubleshooting logs: %USERPROFILE%\Photobooth\logs
Closing the application also stops its local photo service.
Uninstalling or replacing the application does not delete your photo library.
